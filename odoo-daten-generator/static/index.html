API-Fehler

Zum ersten Mal hier?

  1. In Odoo mit dem Benutzer anmelden, dessen Rechte dieser Lauf nutzen soll.
  2. API-Schlüssel erzeugen: im Benutzermenü oben rechts über „Mein Profil“, im Bereich für Kontosicherheit einen neuen API-Schlüssel anlegen und das eigene Passwort bestätigen — der genaue Menüpfad kann je nach Odoo-Version leicht abweichen. Der Schlüssel wird einmalig angezeigt, also sofort kopieren.
  3. Instanz-URL hier eintragen (https://demo-….odoo.com) — die Datenbank wird automatisch daraus abgeleitet, kein eigenes Feld nötig.
  4. LLM-Schlüssel (Groq gsk_… oder Gemini) und Modell eintragen.
  5. „Verbinden“ klicken — die Prüfliste muss vollständig grün sein, bevor es zur Konfiguration weitergeht.
  6. Zur Konfiguration wechseln, Umfang und Module festlegen, „Lauf starten“.
  7. Fertig? „Diesen Lauf löschen“ in der Generierungsansicht räumt alle von diesem Lauf angelegten Datensätze wieder ab.
  8. Etwas unklar, kaputt, oder eine Idee? Der ✉-Knopf unten links schickt kurzes Feedback direkt als GitHub-Issue — jederzeit erreichbar.
